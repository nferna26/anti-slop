# Public Receipts Policy

The public repo should show what was sourced, mapped, carded, promoted, rejected, evaluated, and logged.

Public receipts may include:

- corpus manifest metadata
- acquisition and publication statuses
- book maps
- source cards
- claim/tension cards
- canon candidates
- gate logs
- score sheets
- model-output metadata
- accepted, rejected, and retired registry records
- methodology notes

Public receipts must not include raw copyrighted source files, long excerpts, OCR dumps, extracted book text, or copied chapters.
