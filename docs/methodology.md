# Methodology

Anti-Slop books-kb uses a seven-layer substrate.

1. Source shelf: lawfully acquired books and source material, stored local-only.
2. Book maps: machine-generated or manually drafted triage maps, not canon.
3. Source cards: reviewed evidence units with locators and short excerpts, not canon.
4. Claim/tension cards: synthesis units for competing claims, not canon.
5. Canon candidates: proposed concepts, patterns, guardrails, or playbooks.
6. Canon: operator-approved advisory material.
7. Execution/registry: evals, gate logs, model-output receipts, accepted diffs, rejected diffs, and retired records.

The public repo records the receipt trail. It does not publish the underlying copyrighted corpus.
