# Source Authority Levels

1. Raw source: local-only source material. Never committed.
2. Book map: machine-generated or draft index artifact. Not canon.
3. Source card: reviewed evidence unit. Not canon.
4. Claim/tension card: synthesis unit that preserves competing claims. Not canon.
5. Canon candidate: proposed operator pattern, concept, guardrail, or playbook.
6. Canon: operator-approved advisory substrate.
7. Registry decision: accepted, rejected, or retired record that preserves the decision trail.

Authority increases only through review, source lineage, contradiction handling, and operator approval.
