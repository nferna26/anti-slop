# Canon Promotion Workflow

Canon promotion starts from source cards and claim/tension cards. A candidate must identify support, contradicting sources, existing canon checked, scope conditions, failure modes, and the proposed diff.

Canon requires operator approval. A canon candidate can be promoted, revised, kept as card-only, rejected, or retired.

Use:

```sh
python3 scripts/new_canon_candidate.py <slug>
```

Canon Patch Trial is archived legacy context, not the active workstream and not a gate.
