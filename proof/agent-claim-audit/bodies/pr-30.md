## What

Turns `anti-slop-pr` into an **OSS-preview GitHub PR check** anyone can adopt: a GitHub Actions wrapper that reads the PR body from the event payload and runs the deterministic checker — **no GitHub API, no token**. Claim unchanged: it checks whether a PR description *cites resolvable things*; it does not judge correctness, relevance, support, source truth, advice quality, reasoning, or canon.

Draft for operator review. PR #29 merged at `4365c94`.

## Wrapper

`scripts/pr_provenance_from_github_event.py` (`anti-slop-pr-event`) reads a `pull_request` event JSON (`$GITHUB_EVENT_PATH` or `--event`), extracts the PR body, and runs `anti-slop-pr` against the local checkout (`--root`).
- **Non-PR events SKIP (exit 0)** — by `$GITHUB_EVENT_NAME` or an absent `pull_request.body` — so the same step is harmless on push/comment/schedule, and a malformed/unreadable event SKIPs rather than failing.
- Supports `--root`, `--issue-registry`, `--require-reviewed-cards`, `--report`, `--json`.
- **No GitHub API / network** — event JSON + local files only. Reuses `gate_pr_provenance` unchanged (no fork).
- Hermetic `--self-test` (8 checks: clean PASS, fabricated FAIL, `--report` non-fail, non-PR skip by name + by payload, no-event skip, ignore-directive PASS with audit, non-string-body handled) — clears ambient GitHub env so it passes even *inside* Actions.
- Installable console script `anti-slop-pr-event` (package smoke self-tests it).

## GitHub Actions usage (report by default, enforce opt-in)

```yaml
on: { pull_request: { types: [opened, edited, synchronize, reopened] } }
permissions: { contents: read }   # no token
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - run: pip install "anti-slop-lineage @ git+https://github.com/nferna26/anti-slop"
      - run: anti-slop-pr-event --root . --report   # drop --report to enforce
```
