## Ignore directives (the escape hatch)

```md
<!-- anti-slop-pr: ignore-next-line -->
This line's fabricated example refs are not checked.

<!-- anti-slop-pr: ignore-start -->
A block of example references the checker should not treat as real claims.
<!-- anti-slop-pr: ignore-end -->
```

**Auditable + fail-safe:**
- Only these exact comments suppress checks; any **unknown** comment never does.
- An **unclosed** `ignore-start` is a **no-op** — it hides nothing (checks stay ON to end of file) and is reported as a warning. Stray `ignore-end` / nested `ignore-start` warn too — never silent.
- References **outside** an ignore block are still checked.
- The report and JSON receipt record how many lines were ignored and any warnings, so a reviewer sees exactly what was suppressed.

Applied before ref detection, preserving line numbers; HTML comments still ignored as before.
