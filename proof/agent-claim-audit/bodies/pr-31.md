## What

Ships a **gbrain-style agent-install protocol** for `anti-slop-pr`: point a coding agent at one doc and it installs the checker, wires a report-mode GitHub PR check, runs a smoke, and opens a PR. Claim unchanged: it **resolves** the references a PR description cites; it does **not** verify correctness, relevance, support, source truth, advice quality, reasoning, or canon. No model, network, GitHub API, or token.

Draft for operator review. PR #30 merged at `fb77e48`.

## Install command / prompt

```sh
pip install "anti-slop-lineage @ git+https://github.com/nferna26/anti-slop"
anti-slop-pr --self-test            # 22 checks
anti-slop-pr --root . my-pr-body.md # exit 0 PASS / 1 FAIL / add --report for advisory
```

Copy/paste user prompt (in `INSTALL_FOR_AGENTS.md`, `llms.txt`, README):

> **"Install anti-slop-pr in this repo, run the smoke, add report-mode CI, and open a PR."**

## What is NOT claimed / NOT done

- Resolution only — not correctness/relevance/support/source-truth/advice/reasoning/canon. Only card/source resolution is benchmark-backed; file/test/issue/commit are not.
- No model/API/RAG/vector-store/runtime; no GitHub API or token (checker reads event JSON + local files; install uses pip as documented). Report/advisory default; enforcement explicit opt-in.
- No fork (checker bytes unchanged). No frozen eval / canon / registry / source-card-status change. No secrets, private paths, or raw API JSON (`known-issues.example.txt` is numbers-only). `templates/anti-slop-pr.yml` lives under `templates/`, so it does not run in this repo's CI.
