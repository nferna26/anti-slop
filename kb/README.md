# KB

This folder is the public-safe maintained Markdown knowledgebase.

It exists so Anti-Slop can compound knowledge over time instead of treating every prompt, source, or eval as a one-off event.

## Contract

- `index.md` is the content-oriented navigation layer.
- `log.md` is the chronological memory layer.
- KB pages must be public-safe.
- KB pages must state their authority level when they make advisory claims.
- KB updates should preserve source lineage, contradictions, open questions, and decision history.
- Machine-generated pages may assist discovery, but they are not canon.

## Loops

Ingest:

1. Add or update manifest/acquisition metadata.
2. Create public-safe maps or cards.
3. Update relevant index entries and cross-links.
4. Append a log entry.

Query:

1. Answer from approved KB artifacts.
2. Name source lineage and uncertainty.
3. Preserve contradictions.
4. File useful public-safe outputs back into the KB when appropriate.

Lint:

1. Check for stale pages.
2. Check for missing cross-links.
3. Check for orphan pages.
4. Check for authority-order drift.
5. Check for quote-limit and raw-text risk.
